# Design docs

Reference material behind the pipeline's output format. Kept in the repo so the
pipeline and its agents can be run and understood from this folder alone.

| File | What |
|---|---|
| [feature-specs/proposal.md](feature-specs/proposal.md) | Output structure (one folder per feature, stories with acceptance criteria), template rationale, Linear mapping, pipeline changes |
| [feature-specs/user-story-template.md](feature-specs/user-story-template.md) | The generic user story template: a core for every story, optional sections for data collection and tracker metadata |
| [feature-specs/example-US-03-source-tax-liability.md](feature-specs/example-US-03-source-tax-liability.md) | One data-collection story fully worked out from the real facts (uses the optional sections). Links to `../open-questions.md` and `../traceability.md` refer to the generated requirements folder |
| [research/requirements-format-recommendation.md](research/requirements-format-recommendation.md) | Recommended requirements format |
| [research/agent-requirements-extraction-patterns.md](research/agent-requirements-extraction-patterns.md) | Patterns for agent-based requirements extraction |
| [research/open-source-requirements-pipelines.md](research/open-source-requirements-pipelines.md) | Comparable open-source pipelines |
