# Open questions

What the sources do not settle. Each needs a product decision or a
clarification with the stakeholder. Until then, follow the recommendation.

## OQ-01
**How do we find out whether the canton changes for a move within Switzerland? Options: ask the employee for the new canton on every Swiss move, ask them whether the canton changes, or have HR compare the new address with the canton it already has on record.** _(blocking)_

The new canton should be asked only when the canton changes, but that can't be known without the new canton or the previous canton. Data minimisation (G-01) argues against asking for anything HR already holds.

Options:
- Ask 'Are you moving to a different canton?' and ask for the new canton only if the answer is yes
- HR takes the previous canton from its own records, and the new canton is worked out from the new address or asked only when it differs
- Always ask for the new canton on Swiss moves and keep it only if it changed

**Recommendation:** Clarify with HR (Sara). Prefer taking the previous canton from HR's existing records so the employee is not asked for data HR already has.

Affects: New canton, Previous canton, Move to a different canton
- **F-TR-014**: If the employee moves to a different Swiss canton, the new canton is also needed, for the tax office. — "if someone moves to a different canton, we need the new canton too, for the tax office." (T-008, Sara)
- **F-TR-015**: For a move within the same canton, the new canton is not asked. — "Within the same canton, no." (T-008, Sara)
- **F-TR-017**: To determine whether the canton changes, the previous canton (or current canton) must be known; the stakeholder did not state how. — "if someone moves to a different canton, we need the new canton too" (T-008, Sara)
- **G-01**: Ask only what a stakeholder needs for this person (data minimisation).

## OQ-02
**Is there a latest allowed valid-from date in the future?**

The meeting gave only a limit for past dates. Without a limit for the future, a move could be reported for any date ahead.

Options:

- A fixed future limit (e.g. a number of months ahead)

**Recommendation:** Confirm with HR. Until then, apply no future limit.

Affects: Valid from, Valid-from date at most three months in the past
- **F-TR-021**: No upper limit for a future valid-from date was stated. — "It can be in the past, people often tell us late, but not more than three months ago." (T-010, Sara)
