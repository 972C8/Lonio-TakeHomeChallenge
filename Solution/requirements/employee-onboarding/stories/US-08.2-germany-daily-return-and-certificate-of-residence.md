# US-08.2 – Germany: daily return and certificate of residence

Part of [Employee onboarding questionnaire](../feature.md), section [8. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** every employee living in Germany to state whether they expect to return daily to their main residence in Germany and, if so, whether they have a certificate of residence, **so that** Lonio can decide, as the Zurich calculator does, whether the cross-border tariff or the normal tariff applies and compute the correct tariff code

Priority **P1** – Lonio now computes the tariff code instead of HR (D-001); without these answers the tariff for Germany residents is wrong, and HR finds the cross-border cases the most complicated (F-hr_transcript-8595fb). · Status: **decision** · Sources: F-zh_source_tax_calculator-69edd5, F-zh_source_tax_calculator-64ac42, F-zh_source_tax_calculator-31d762, F-zh_source_tax_calculator-687e8b, F-zh_source_tax_calculator-823151, F-zh_source_tax_calculator-5f6820, F-zh_source_tax_calculator-993db3, F-zh_source_tax_calculator-66732c, F-hr_transcript-8595fb, F-hr_transcript-3f2c2a, D-001, D-006, D-009, D-034, D-035, D-045

Covers (details in [the section](../feature.md#SEC-08-cross-border-residence) and [information.md](../information.md)): Daily return to Germany, Certificate of residence, Cross-border tariff applies

## Acceptance criteria

- **AC-08.2.1 Daily return to Germany is asked of every Germany resident**
  - **Given** the employee's home address on the first working day is in Germany (so they are subject to source tax whatever their nationality)
  - **When** the employee reaches the source tax questions
  - **Then** the employee is asked whether they expect to return daily to their main residence in Germany, answered 'yes' or 'no'; the answer is required; it is not asked of anyone living elsewhere. The answer is used for the source tax tariff code and recorded for HR
  - _Sources: F-zh_source_tax_calculator-69edd5, F-zh_source_tax_calculator-64ac42, F-zh_source_tax_calculator-31d762, F-hr_transcript-3f2c2a, D-006, D-034, D-035_

  | Example | Country (of residence) | → | Daily return to Germany | Certificate of residence | Checked |
  |---|---|---|---|---|---|
  | Employee living in Germany (illustrative) | Germany | → | required | – | ✅ |
  | Employee living in Liechtenstein (illustrative) | Liechtenstein | → | not asked | not asked | ✅ |

- **AC-08.2.2 Certificate of residence is asked only with daily return**
  - **Given** the employee lives in Germany
  - **When** the employee answers the daily return question
  - **Then** only with 'yes' is the employee asked whether they have a certificate of residence, answered 'yes', 'no' or 'not yet'; the answer is required when asked. 'not yet' is a valid answer for a new hire. The certificate itself is handed to HR outside Lonio; Lonio offers no upload
  - _Sources: F-zh_source_tax_calculator-687e8b, F-zh_source_tax_calculator-823151, F-zh_source_tax_calculator-5f6820, D-035_

  | Example | Country (of residence) | Daily return to Germany | → | Certificate of residence | Daily return reasonable (under 100 km) | More than 60 non-return days (Germany) | Checked |
  |---|---|---|---|---|---|---|---|
  | Daily return to Germany (illustrative) | Germany | yes | → | required | not asked | not asked | ✅ |
  | No daily return to Germany (illustrative) | Germany | no | → | not asked | – | – | ✅ |

- **AC-08.2.3 Daily return with certificate gives the cross-border tariff**
  - **Given** the employee lives in Germany and expects to return daily
  - **When** Lonio decides between cross-border and normal tariff
  - **Then** with a certificate of residence ('yes') the cross-border tariff applies (A becomes L, B becomes M, C becomes N, H becomes P); with 'no' or 'not yet' the normal tariff applies. The result is always derived again from the latest answers. Cross-border results for tariffs A, B and H were only spot-checked in the calculator and are part of the go-live comparison (see OQ-calculator-coverage)
  - _Sources: F-zh_source_tax_calculator-993db3, F-zh_source_tax_calculator-66732c, D-001, D-009, D-035, D-037_

  | Example | Country (of residence) | Daily return to Germany | Certificate of residence | → | Cross-border tariff applies | Checked |
  |---|---|---|---|---|---|---|
  | Calculator: daily return with certificate gives N1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-993db3) | Germany | yes | yes | → | yes | ✅ |
  | Calculator: daily return without certificate gives C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-993db3) | Germany | yes | no | → | no | ✅ |
  | Certificate not yet available counts as no (illustrative) | Germany | yes | not yet | → | no | ✅ |
