# US-08.3 – Germany: no daily return - reasonableness and more than 60 non-return days

Part of [Employee onboarding questionnaire](../feature.md), section [8. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** an employee living in Germany who does not expect to return daily to state whether daily return would basically be reasonable (less than 100 km driving distance) and, if so, whether they expect more than 60 work-related non-return days in the calendar year, **so that** Lonio can decide, as the Zurich calculator does, whether the cross-border tariff or the normal tariff applies

Priority **P1** – Lonio computes the tariff code itself (D-001); a missing or wrong answer leads to a wrong tariff for Germany residents. · Status: **decision** · Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6, F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-66732c, F-hr_transcript-8595fb, D-001, D-006, D-009, D-034, D-035, D-045

Covers (details in [the section](../feature.md#SEC-08-cross-border-residence) and [information.md](../information.md)): Daily return reasonable (under 100 km), More than 60 non-return days (Germany), Cross-border tariff applies

## Acceptance criteria

- **AC-08.3.1 Reasonableness of daily return is asked without daily return**
  - **Given** the employee lives in Germany and answered that they do not expect to return daily
  - **When** the employee continues with the source tax questions
  - **Then** the employee is asked whether daily return would basically be reasonable (less than 100 km driving distance), answered 'yes' or 'no'; the answer is required; it is not asked of employees who return daily or live elsewhere. The answer is used for the tariff code and recorded for HR
  - _Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6, D-034_

  | Example | Country (of residence) | Daily return to Germany | → | Daily return reasonable (under 100 km) | More than 60 non-return days (Germany) | Checked |
  |---|---|---|---|---|---|---|
  | Germany, no daily return (illustrative) | Germany | no | → | required | – | ✅ |
  | Germany, daily return (illustrative) | Germany | yes | → | not asked | not asked | ✅ |

- **AC-08.3.2 More than 60 non-return days is asked only when daily return is reasonable**
  - **Given** the employee lives in Germany, does not expect to return daily, and daily return would be reasonable
  - **When** the employee answers the reasonableness question with 'yes'
  - **Then** the employee is asked whether they expect more than 60 work-related non-return days in the calendar year, answered 'yes' or 'no'; the answer is required when asked. The employee states their expectation for the year rather than proof as in the calculator; any proof goes to HR outside Lonio, with no upload. With 'no' to reasonableness the question is not asked
  - _Sources: F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, D-035_

  | Example | Country (of residence) | Daily return to Germany | Daily return reasonable (under 100 km) | → | More than 60 non-return days (Germany) | Checked |
  |---|---|---|---|---|---|---|
  | Daily return reasonable (illustrative) | Germany | no | yes | → | required | ✅ |
  | Daily return not reasonable (illustrative) | Germany | no | no | → | not asked | ✅ |

- **AC-08.3.3 Tariff without daily return**
  - **Given** the employee lives in Germany and does not expect to return daily
  - **When** Lonio decides between cross-border and normal tariff
  - **Then** if daily return is not reasonable, the normal tariff applies; if it is reasonable and more than 60 non-return days are expected, the normal tariff applies; if it is reasonable and no more than 60 non-return days are expected, the cross-border tariff applies (A becomes L, B becomes M, C becomes N, H becomes P). The result is always derived again from the latest answers. Cross-border results for tariffs A, B and H are part of the go-live comparison (see OQ-calculator-coverage)
  - _Sources: F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-993db3, F-zh_source_tax_calculator-66732c, D-001, D-009, D-035, D-037_

  | Example | Country (of residence) | Daily return to Germany | Daily return reasonable (under 100 km) | More than 60 non-return days (Germany) | → | Cross-border tariff applies | Checked |
  |---|---|---|---|---|---|---|---|
  | Calculator: reasonable, not more than 60 days gives N1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | yes | no | → | yes | ✅ |
  | Calculator: reasonable, more than 60 days gives C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | yes | yes | → | no | ✅ |
  | Calculator: daily return not reasonable gives C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | no | – | → | no | ✅ |
