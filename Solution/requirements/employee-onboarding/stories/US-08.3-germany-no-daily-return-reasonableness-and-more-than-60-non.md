# US-08.3 – Germany: no daily return - reasonableness and more than 60 non-return days

Part of [Employee onboarding questionnaire](../feature.md), section [6. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** employees living in Germany who do not return daily to state whether a daily return would be reasonable and whether they expect more than 60 work-related non-return days in the year, **so that** the cross-border tariff or the normal tariff is applied as the calculator prescribes

Priority **P1** – Decides the tariff letter of the computed tariff code (D-001); a wrong letter means wrong source tax deductions. · Status: **decision** · Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6, F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-f86c6b, D-001, D-035

Covers (details in [the section](../feature.md#SEC-08-cross-border-residence) and [information.md](../information.md)): Daily return reasonable, More than 60 non-return days (Germany), Cross-border (Grenzgänger) tariff applies

## Acceptance criteria

- **AC-08.3.1 Reasonableness of daily return is asked without daily return**
  - **Given** the employee lives in Germany
  - **When** the employee answers that they do not return daily
  - **Then** the employee is asked whether a daily return would in principle be reasonable (less than 100 km driving distance); the answer is required and is 'yes' or 'no'. Employees who return daily are not asked.
  - _Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6_

  | Example | Country of residence (home address country) | Daily return to Germany | → | Daily return reasonable | Checked |
  |---|---|---|---|---|---|
  | Germany, no daily return (illustrative) | Germany | no | → | required | ✅ |
  | Germany, daily return (illustrative) | Germany | yes | → | not asked | ✅ |

- **AC-08.3.2 More than 60 non-return days is asked only when daily return is reasonable**
  - **Given** the employee lives in Germany and does not return daily
  - **When** the employee answers that a daily return would be reasonable
  - **Then** the employee is asked whether they expect more than 60 work-related non-return days in the calendar year; the answer is required and is 'yes' or 'no'. It is a declaration of what the employee expects, not proof, and nothing is uploaded. When a daily return is not reasonable, the question is not asked.
  - _Sources: F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, D-035_

  | Example | Country of residence (home address country) | Daily return to Germany | Daily return reasonable | → | More than 60 non-return days (Germany) | Checked |
  |---|---|---|---|---|---|---|
  | Reasonable (illustrative) | Germany | no | yes | → | required | ✅ |
  | Not reasonable (illustrative) | Germany | no | no | → | not asked | ✅ |

- **AC-08.3.3 Tariff without daily return**
  - **Given** the employee lives in Germany and does not return daily
  - **When** Lonio decides between the cross-border and the normal tariff
  - **Then** if a daily return is not reasonable, the normal tariff applies; if it is reasonable and the employee expects more than 60 non-return days, the normal tariff applies; if it is reasonable and the employee does not expect more than 60 non-return days, the cross-border tariff applies. Employees not living in Germany never get the German cross-border tariff.
  - _Sources: F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-f86c6b, D-001, D-035_

  | Example | Country of residence (home address country) | Daily return to Germany | Daily return reasonable | More than 60 non-return days (Germany) | → | Cross-border (Grenzgänger) tariff applies | Checked |
  |---|---|---|---|---|---|---|---|
  | Calculator example reasonable, no >60 days -> N1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | yes | no | → | yes | ✅ |
  | Calculator example reasonable, >60 days -> C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | yes | yes | → | no | ✅ |
  | Calculator example not reasonable -> C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | no | – | → | no | ✅ |
  | Lives in France (illustrative) | France | – | – | – | → | no | ✅ |
