# US-08.3 – Germany: no daily return - reasonableness and more than 60 non-return days

Part of [Employee onboarding questionnaire](../feature.md), section [8. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** employees living in Germany who do not return daily to be asked whether a daily return would basically be reasonable (less than 100 km driving distance) and, if so, whether they expect more than 60 work-related non-return days in the calendar year, **so that** the cross-border tariff or the normal tariff is applied as the calculator would apply it

Priority **P1** – Without these answers Lonio cannot compute the tariff code for Germany residents who do not return daily (D-001). · Status: **decision** · Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6, F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-66732c, D-001, D-035

Covers (details in [the section](../feature.md#SEC-08-cross-border-residence) and [information.md](../information.md)): Daily return reasonable (less than 100 km), More than 60 work-related non-return days expected (Germany), Cross-border (Grenzgänger) tariff applies

## Acceptance criteria

- **AC-08.3.1 Reasonableness of a daily return is asked only when the employee does not return daily**
  - **Given** an employee living in Germany is subject to source tax (everyone living abroad is)
  - **When** they answer that they do not return daily to their main residence in Germany
  - **Then** They are asked whether a daily return would basically be reasonable (less than 100 km driving distance), answered 'yes' or 'no'. The answer is required. Employees who return daily, or who live outside Germany, are not asked. The answer is recorded for source tax.
  - _Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6_

  | Example | Country of residence (country of the home address) | Returns daily to the home in Germany | → | Daily return reasonable (less than 100 km) | More than 60 work-related non-return days expected (Germany) | Checked |
  |---|---|---|---|---|---|---|
  | Germany resident not returning daily (illustrative) | Germany | no | → | required | – | ✅ |
  | Germany resident returning daily (illustrative) | Germany | yes | → | not asked | not asked | ✅ |

- **AC-08.3.2 More than 60 non-return days is asked only when a daily return is reasonable**
  - **Given** an employee living in Germany who is subject to source tax does not return daily
  - **When** they answer that a daily return would be reasonable
  - **Then** They are asked whether they expect more than 60 work-related non-return days in the calendar year, answered 'yes' or 'no'. The answer is required. The employee states what they expect for the year; no proof is collected in Lonio. If a daily return is not reasonable, the question is not asked.
  - _Sources: F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, D-035_

  | Example | Country of residence (country of the home address) | Returns daily to the home in Germany | Daily return reasonable (less than 100 km) | → | More than 60 work-related non-return days expected (Germany) | Checked |
  |---|---|---|---|---|---|---|
  | Return reasonable (illustrative) | Germany | no | yes | → | required | ✅ |
  | Return not reasonable (illustrative) | Germany | no | no | → | not asked | ✅ |

- **AC-08.3.3 Tariff decision for Germany residents who do not return daily**
  - **Given** an employee living in Germany who is subject to source tax does not return daily
  - **When** Lonio computes the tariff code
  - **Then** If a daily return is not reasonable, the normal tariff applies. If it is reasonable and the employee expects more than 60 non-return days, the normal tariff applies. If it is reasonable and they do not expect more than 60, the cross-border tariff applies, which changes the tariff letter (see the tariff letter rule). The A/B/H paths are verified before go-live (see OQ-calculator-coverage).
  - _Sources: F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-66732c, D-001, D-035_

  | Example | Country of residence (country of the home address) | Returns daily to the home in Germany | Daily return reasonable (less than 100 km) | More than 60 work-related non-return days expected (Germany) | → | Cross-border (Grenzgänger) tariff applies | Checked |
  |---|---|---|---|---|---|---|---|
  | Calculator run: return not reasonable, result C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | no | – | → | no | ✅ |
  | Calculator run: reasonable, more than 60 days, result C1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | yes | yes | → | no | ✅ |
  | Calculator run: reasonable, not more than 60 days, result N1Y (zh_source_tax_calculator/F-zh_source_tax_calculator-c8aa5e) | Germany | no | yes | no | → | yes | ✅ |
