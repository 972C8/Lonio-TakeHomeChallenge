# US-08.3 – Germany: no daily return - reasonableness and more than 60 non-return days

Part of [Employee onboarding questionnaire](../feature.md), section [6. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** an employee living in Germany who does not return daily to be asked whether a daily return would basically be reasonable (less than 100 km driving distance) and, if so, whether they expect more than 60 work-related non-return days in the calendar year, **so that** Lonio can decide, as the calculator does, whether the cross-border tariff or the normal tariff applies

Priority **P1** – The answers decide between the cross-border and the normal tariff letter (calculator: N1Y vs C1Y); Lonio cannot compute the tariff code without them (D-001). · Status: **decision** · Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6, F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, F-zh_source_tax_calculator-c8aa5e, D-001, D-035, D-051

Covers (details in [the section](../feature.md#SEC-08-cross-border-residence) and [information.md](../information.md)): Daily return reasonable (less than 100 km), More than 60 work-related non-return days (Germany), Cross-border tariff applies (Germany)

## Acceptance criteria

- **AC-08.3.1 Reasonableness of daily return is asked only without daily return**
  - **Given** the employee lives in Germany
  - **When** the employee answers that they do not return daily to their main residence in Germany
  - **Then** the employee is asked whether a daily return would basically be reasonable (less than 100 km driving distance), answering 'yes' or 'no'; the answer is required and recorded for source tax; it is not asked when the employee returns daily or lives in another country
  - _Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-aaece6_

  | Example | Country of residence (country of the home address) | Daily return to Germany | → | Daily return reasonable (less than 100 km) | Checked |
  |---|---|---|---|---|---|
  | Calculator: asked after daily return 'Nein' (zh_source_tax_calculator/F-aaece6) | Germany | no | → | required | ✅ |
  | Daily return - not asked (illustrative) | Germany | yes | → | not asked | ✅ |

- **AC-08.3.2 More than 60 non-return days is asked only when daily return is reasonable**
  - **Given** the employee lives in Germany and does not return daily
  - **When** the employee answers that a daily return would be reasonable
  - **Then** the employee is asked whether they expect more than 60 work-related non-return days in the calendar year, answering 'yes' or 'no'; the answer is a statement of what the employee expects, not proof, and no document is asked or uploaded (D-035); it is required and recorded for source tax; it is not asked when a daily return is not reasonable
  - _Sources: F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-33ef31, D-035_

  | Example | Country of residence (country of the home address) | Daily return to Germany | Daily return reasonable (less than 100 km) | → | More than 60 work-related non-return days (Germany) | Checked |
  |---|---|---|---|---|---|---|
  | Calculator: asked after reasonable 'Ja' (zh_source_tax_calculator/F-33ef31) | Germany | no | yes | → | required | ✅ |
  | Return not reasonable - not asked (illustrative) | Germany | no | no | → | not asked | ✅ |

- **AC-08.3.3 Cross-border tariff without daily return**
  - **Given** the employee lives in Germany and does not return daily
  - **When** Lonio decides whether the cross-border tariff applies
  - **Then** if a daily return is not reasonable, the normal tariff applies; if it is reasonable and the employee expects more than 60 non-return days, the normal tariff applies; if it is reasonable and the employee does not expect more than 60 non-return days, the cross-border tariff applies, with the letters as in the calculator (assumption D-051, to be verified by a domain expert)
  - _Sources: F-zh_source_tax_calculator-c8aa5e, D-035, D-051, D-001_

  | Example | Country of residence (country of the home address) | Daily return to Germany | Daily return reasonable (less than 100 km) | More than 60 work-related non-return days (Germany) | → | Cross-border tariff applies (Germany) | Checked |
  |---|---|---|---|---|---|---|---|
  | Calculator: not reasonable gives C1Y (zh_source_tax_calculator/F-c8aa5e) | Germany | no | no | – | → | no | ✅ |
  | Calculator: reasonable and more than 60 days gives C1Y (zh_source_tax_calculator/F-c8aa5e) | Germany | no | yes | yes | → | no | ✅ |
  | Calculator: reasonable and not more than 60 days gives N1Y (zh_source_tax_calculator/F-c8aa5e) | Germany | no | yes | no | → | yes | ✅ |
