# US-08.3 – Germany: no daily return - reasonableness and proof of more than 60 non-return days

Part of [Employee onboarding questionnaire](../feature.md), section [8. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** employees living in Germany who do not return daily to say whether daily return is basically reasonable (driving distance under 100 km) and, if so, whether proof of more than 60 work-related non-return days in the calendar year has been provided, **so that** the calculator can decide between the cross-border tariff and the normal tariff for employees who stay in Switzerland overnight

Priority **P1** – Without these answers the tariff of a Germany resident who does not return daily cannot be determined (F-zh_source_tax_calculator-c8aa5e, F-hr_transcript-8595fb). · Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-580ad4, F-zh_source_tax_calculator-aaece6, F-zh_source_tax_calculator-5373ec, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-a18842, F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ab4fae, F-zh_source_tax_calculator-33ef31, F-zh_source_tax_calculator-6746d6, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-bab153, F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-2754e8, F-hr_transcript-8595fb

## Acceptance criteria

- **AC-08.3.1 Reasonableness of daily return is asked only without daily return**
  - **Given** the employee lives in Germany, is subject to source tax and has answered whether they return daily to their home in Germany
  - **When** the answer is 'no'
  - **Then** the employee must answer 'yes' or 'no' to whether daily return is basically reasonable (driving distance under 100 km); for replacement income the question refers to the time during or before receiving it. If it is not reasonable, the normal tariff applies. Employees who return daily are not asked. The answer is needed by source tax only
  - _Sources: F-zh_source_tax_calculator-d2b3cf, F-zh_source_tax_calculator-580ad4, F-zh_source_tax_calculator-aaece6, F-zh_source_tax_calculator-5373ec, F-zh_source_tax_calculator-087ae5, F-zh_source_tax_calculator-c8aa5e_

  | Example | Country (of the home address) | Type of income (source tax) | Returns daily to the home in Germany | → | Daily return reasonable (under 100 km) | Checked |
  |---|---|---|---|---|---|---|
  | Germany resident not returning daily, earned income (illustrative) | Germany | Earned income | no | → | required | ✅ |
  | Germany resident not returning daily, replacement income (illustrative) | Germany | Replacement income | no | → | required | ✅ |
  | Germany resident returning daily (illustrative) | Germany | Earned income | yes | → | not asked | ✅ |

- **AC-08.3.2 Proof of more than 60 non-return days is asked only when daily return is reasonable**
  - **Given** the employee lives in Germany, is subject to source tax and does not return daily
  - **When** the employee answers that daily return is basically reasonable
  - **Then** the employee must answer 'yes' or 'no' to whether proof of more than 60 work-related non-return days in the calendar year has been provided (for replacement income: during or before receiving it); with proof the normal tariff applies, without it the cross-border tariff. If daily return is not reasonable, the question is not asked. Whether a new employee can already answer this, and to whom the proof is provided, is open (see OQ-proof-documents). The answer is needed by source tax only
  - _Sources: F-zh_source_tax_calculator-e8ffac, F-zh_source_tax_calculator-ab4fae, F-zh_source_tax_calculator-33ef31, F-zh_source_tax_calculator-6746d6, F-zh_source_tax_calculator-ea3cd8, F-zh_source_tax_calculator-c8aa5e, F-zh_source_tax_calculator-2754e8_

  | Example | Country (of the home address) | Type of income (source tax) | Returns daily to the home in Germany | Daily return reasonable (under 100 km) | → | Proof of more than 60 work-related non-return days | Checked |
  |---|---|---|---|---|---|---|---|
  | Germany resident, daily return reasonable (illustrative) | Germany | Earned income | no | yes | → | required | ✅ |
  | Germany resident, daily return not reasonable (illustrative) | Germany | Earned income | no | no | → | not asked | ✅ |
