# US-06.6 – Compute and record the full source tax tariff code

Part of [Employee onboarding questionnaire](../feature.md), section [6. Source tax tariff: denomination, spouse employment and tariff code](../feature.md#SEC-06-source-tax-tariff-basics).

**As** HR, **I want** Lonio to compute the complete Zurich tariff code (final tariff letter, child digit, church-tax suffix) for every employee subject to source tax and record it for me, **so that** I no longer have to sit with the answers and click through the canton's calculator for each new employee

Priority **P1** – HR's current process is a manual walk-through of the calculator for each employee (F-hr_transcript-3cd6fa). Replacing it is an explicit product decision (D-001). · Status: **decision** · Sources: F-hr_transcript-34494f, F-hr_transcript-3cd6fa, F-hr_transcript-5af8d0, F-zh_source_tax_calculator-4c53e3, F-zh_source_tax_calculator-2eab9a, F-zh_source_tax_calculator-993db3, F-zh_source_tax_calculator-fb87f1, F-zh_source_tax_calculator-cc19c7, F-zh_source_tax_calculator-86d588, D-001, D-007, D-009, D-034, D-037

Covers (details in [the section](../feature.md#SEC-06-source-tax-tariff-basics) and [information.md](../information.md)): Source tax tariff code

## Acceptance criteria

- **AC-06.6.1 Tariff code is letter, child digit and suffix**
  - **Given** an employee subject to source tax who does not fall under the Liechtenstein no-liability case
  - **When** Lonio computes the tariff code from the employee's answers
  - **Then** the tariff code is the final tariff letter, then the child digit (the number of children that count, with or without H; 0 without children), then the church-tax suffix, for example A0N, C1Y, L0Y or N1Y. The code is recorded for HR. Paths the calculator was not explored for (residence block for A/B/H, more than 3 children, H3N/P3N) are checked against the calculator before go-live (see OQ-calculator-coverage).

- **AC-06.6.2 Liechtenstein residents with daily return or at most 45 non-return days get no tariff code**
  - **Given** an employee living in Liechtenstein who returns daily, or who does not return daily and expects at most 45 work-related non-return days
  - **When** Lonio computes the source tax result
  - **Then** instead of a tariff code, Lonio records 'in principle no source tax liability, subject to the double taxation agreement' for HR and flags the case for HR. How HR sees the flag belongs to the later HR-side spec (D-034).
  - _Sources: F-zh_source_tax_calculator-fb87f1, D-007, D-034_

- **AC-06.6.3 Employees not subject to source tax get no tariff code**
  - **Given** an employee who is not subject to source tax (rule subject_to_source_tax)
  - **When** the employee submits the questionnaire
  - **Then** no tariff code is computed or recorded for this employee, and none of the source tax questions were asked.
  - _Sources: F-hr_transcript-5af8d0, F-hr_transcript-b84498, G-01_

- **AC-06.6.4 Tariff code always reflects the latest answers**
  - **Given** an employee whose answers that feed the tariff code have changed, either before submission or later by HR (for example a marriage, a new child, or a certificate of residence handed in after a 'not yet')
  - **When** the tariff code is looked at
  - **Then** it is always derived again from the latest answers. No earlier code is kept as the result. How HR changes answers after submission belongs to the later HR-side spec (D-034, D-037).
  - _Sources: D-037, D-034, D-035_
