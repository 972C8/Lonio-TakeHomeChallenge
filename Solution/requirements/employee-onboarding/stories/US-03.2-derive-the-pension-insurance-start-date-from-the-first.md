# US-03.2 – Derive the pension insurance start date from the first working day

Part of [Employee onboarding questionnaire](../feature.md), section [3. First working day and insurance start date](../feature.md#SEC-03-employment-start).

**As** pension fund, **I want** the insurance start date for each new employee to be derived from their first working day and always fall on the 1st of a month, **so that** every registration carries a valid, correct insurance start date without the employee having to know the pension fund's rule

Priority **P1** – The insurance start date is a required field of the pension registration and must be the 1st of a month; a wrong date has already led to an unfriendly letter from the fund and weeks of fixing. · Sources: F-hr_transcript-1d5c07, F-hr_transcript-30d25c, F-hr_transcript-fdf50a, F-pension_portal-509cbe, F-pension_portal-dd8126, F-pension_portal-3a97ab, G-08

Covers (details in [the section](../feature.md#SEC-03-employment-start) and [information.md](../information.md)): First working day, Pension insurance start date

## Acceptance criteria

- **AC-03.2.1 First working day on the 1st of a month: insurance starts that day**
  - **Given** the employee's confirmed first working day is the 1st of a month
  - **When** the insurance start date is determined
  - **Then** the insurance start date is the first working day itself
  - _Sources: F-hr_transcript-fdf50a, F-hr_transcript-1d5c07_

  | Example | First working day | → | Pension insurance start date | Checked |
  |---|---|---|---|---|
  | Start on the 1st of March (illustrative) | 01.03.2026 | → | 01.03.2026 | ✅ |
  | Start on the 1st of January (illustrative) | 01.01.2027 | → | 01.01.2027 | ✅ |

- **AC-03.2.2 First working day not on the 1st: insurance starts on the 1st of the following month**
  - **Given** the employee's confirmed first working day is any day other than the 1st of a month
  - **When** the insurance start date is determined
  - **Then** the insurance start date is the 1st of the month following the first working day, including across a year end
  - _Sources: F-hr_transcript-30d25c, F-hr_transcript-1d5c07_

  | Example | First working day | → | Pension insurance start date | Checked |
  |---|---|---|---|---|
  | Julia (hr_transcript/F-hr_transcript-30d25c), year illustrative | 15.03.2026 | → | 01.04.2026 | ✅ |
  | Start on the 2nd of a month (illustrative) | 02.06.2026 | → | 01.07.2026 | ✅ |
  | Start on the last day of a month (illustrative) | 31.01.2026 | → | 01.02.2026 | ✅ |
  | Mid-December start crosses the year end (illustrative) | 15.12.2026 | → | 01.01.2027 | ✅ |

- **AC-03.2.3 Insurance start date is derived, never asked**
  - **Given** any new employee
  - **When** they fill in the questionnaire
  - **Then** they are not asked for an insurance start date; the pension fund receives the derived date, which is always the 1st of a month and given as DD.MM.YYYY as its registration requires
  - _Sources: G-08, F-pension_portal-509cbe, F-pension_portal-dd8126, F-pension_portal-3a97ab_

## Evidence
- **F-hr_transcript-1d5c07** (hr_transcript, inferred): Consolidated rule: the insurance start date is derived from the first working day. If the first working day is the 1st of a month, insurance starts that day. Otherwise it starts on the 1st of the following month.
  - "because insurance starts on the first of the following month." — hr_transcript/T-026, Anna
  - "Unless somebody starts exactly on the first, of course, then it's just that day." — hr_transcript/T-028, Anna
- **F-hr_transcript-30d25c** (hr_transcript): First version: pension fund insurance starts on the first day of the month after the first working day (for example, first working day 15.03 gives insurance start 01.04).
  - "because insurance starts on the first of the following month. So for her that was the first of April" — hr_transcript/T-026, Anna
- **F-hr_transcript-fdf50a** (hr_transcript): Exception: if the first working day is the first day of a month, insurance starts on that same day.
  - "Unless somebody starts exactly on the first, of course, then it's just that day." — hr_transcript/T-028, Anna
- **F-pension_portal-3a97ab** (pension_portal, inferred): The portal requires an insurance start date on the 1st of a month but does not show how it relates to the employee's first working day (e.g. which 1st of a month to choose when work starts mid-month); the derivation rule is unknown.
  - "DD.MM.YYYY. Must be the 1st of a month." — 01-empty.png (pension_portal/S01-E14)
- **F-pension_portal-509cbe** (pension_portal): The pension fund registration form has a text field 'Insurance start date' in the Insurance section, marked required.
  - "Insurance start date" — 01-empty.png (pension_portal/S01-E13)
  - "Insurance" — 01-empty.png (pension_portal/S01-E12)
- **F-pension_portal-dd8126** (pension_portal): Insurance start date must be in the format DD.MM.YYYY and must be the 1st of a month.
  - "DD.MM.YYYY. Must be the 1st of a month." — 01-empty.png (pension_portal/S01-E14)
- **G-08** (product owner guidance): Prefer asking for primary facts and **deriving** values (e.g. ask the first working day, derive the insurance start date) instead of asking the employee for values they cannot know.
