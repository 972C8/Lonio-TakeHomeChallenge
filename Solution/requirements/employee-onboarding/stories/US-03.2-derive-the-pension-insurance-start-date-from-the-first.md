# US-03.2 – Derive the pension insurance start date from the first working day

Part of [Employee onboarding questionnaire](../feature.md), section [3. First working day and insurance start date](../feature.md#SEC-03-employment-start).

**As** pension fund, **I want** to receive an insurance start date on the 1st of a month, derived from the employee's first working day, **so that** the registration's required 'Insurance start date' is valid without the employee having to know or work out the fund's rule

Priority **P1** – The 'Insurance start date' is a required field of the fund registration and must be the 1st of a month (F-pension_portal-509cbe, F-pension_portal-dd8126). A wrong date led to an unfriendly letter and weeks of fixing (F-hr_transcript-e18e66). · Sources: F-hr_transcript-1d5c07, F-pension_portal-509cbe, F-pension_portal-dd8126, G-08, D-039, D-045

Covers (details in [the section](../feature.md#SEC-03-employment-start) and [information.md](../information.md)): First working day, Insurance start date

## Acceptance criteria

- **AC-03.2.1 Insurance start date is derived, never asked**
  - **Given** an employee fills in the onboarding questionnaire
  - **When** they go through all steps
  - **Then** they are never asked for the insurance start date. Lonio derives it from the first working day and records it for the pension fund as a date in the format DD.MM.YYYY that is always the 1st of a month.
  - _Sources: F-hr_transcript-1d5c07, F-pension_portal-509cbe, F-pension_portal-dd8126, G-08_
- **AC-03.2.2 First working day on the 1st of a month**
  - **Given** the first working day is the 1st of a month
  - **When** the insurance start date is derived
  - **Then** insurance starts on the first working day itself. This also applies when that day is a weekend or public holiday, because the first working day is the contractual start date. Assumption, to be verified by a domain expert: see D-039.
  - _Sources: F-hr_transcript-1d5c07, D-039_

  | Example | First working day | → | Insurance start date | Checked |
  |---|---|---|---|---|
  | Start on the 1st of a month (illustrative) | 01.03.2026 | → | 01.03.2026 | ✅ |
  | Contractual start on a Saturday and Swiss National Day (illustrative) | 01.08.2026 | → | 01.08.2026 | ✅ |

- **AC-03.2.3 First working day on any other day**
  - **Given** the first working day is not the 1st of a month
  - **When** the insurance start date is derived
  - **Then** insurance starts on the 1st of the following month, including across a year end.
  - _Sources: F-hr_transcript-1d5c07, F-pension_portal-dd8126_

  | Example | First working day | → | Insurance start date | Checked |
  |---|---|---|---|---|
  | Julia (hr_transcript/F-hr_transcript-e18e66), start moved to 15 March (year assumed) | 15.03.2026 | → | 01.04.2026 | ✅ |
  | Start on the 2nd of a month (illustrative) | 02.11.2026 | → | 01.12.2026 | ✅ |
  | Start at the end of the year (illustrative) | 31.12.2026 | → | 01.01.2027 | ✅ |


## Evidence
- **D-039** (product decision (Product owner)): The first working day is the contractual start date, even when it falls on a weekend or public holiday. The insurance start date is derived from this date only. Assumption - to be verified by a domain expert; state this assumption in the user story.
- **D-045** (product decision (Product owner)): Business text (stories, acceptance criteria, notices) uses no internal snake_case ids and does not speak of 'expressions'. Any behaviour that has no cited fact or decision is stated in the story as an assumption. Assumption - to be verified by a domain expert; state this assumption in the user story.
- **F-hr_transcript-1d5c07** (hr_transcript): Consolidated rule: the insurance start date is derived from the first working day. If the first working day is the 1st of a month, insurance starts that day. Otherwise it starts on the 1st of the following month.
  - "because insurance starts on the first of the following month." — hr_transcript/T-026, Anna
  - "Unless somebody starts exactly on the first, of course, then it's just that day." — hr_transcript/T-028, Anna
- **F-pension_portal-509cbe** (pension_portal): The pension fund registration form has a text field 'Insurance start date' in the Insurance section, marked required.
  - "Insurance start date" — 01-empty.png (pension_portal/S01-E13)
  - "Insurance" — 01-empty.png (pension_portal/S01-E12)
- **F-pension_portal-dd8126** (pension_portal): Insurance start date must be in the format DD.MM.YYYY and must be the 1st of a month.
