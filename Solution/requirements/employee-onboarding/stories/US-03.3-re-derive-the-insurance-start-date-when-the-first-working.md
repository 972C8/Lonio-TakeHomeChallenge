# US-03.3 – Re-derive the insurance start date when the first working day moves

Part of [Employee onboarding questionnaire](../feature.md), section [3. First working day and insurance start date](../feature.md#SEC-03-employment-start).

**As** HR, **I want** the insurance start date to be derived again whenever the employee's first working day changes, **so that** a moved start date never leaves a wrong insurance start date at the pension fund, as happened with Julia

Priority **P1** – A missed update after Julia moved her start caused a wrong date at the pension fund, an unfriendly letter and weeks of fixing. · Status: **inferred** · Sources: F-hr_transcript-e18e66, F-hr_transcript-e3721e, F-hr_transcript-1d5c07, G-04

Covers (details in [the section](../feature.md#SEC-03-employment-start) and [information.md](../information.md)): First working day, Pension insurance start date

## Acceptance criteria

- **AC-03.3.1 Changed first working day gives a newly derived insurance start date**
  - **Given** an employee's first working day has been recorded and later changes to a different date
  - **When** the new first working day is recorded
  - **Then** the insurance start date is derived again from the new date using the same rule (1st of a month stays that day, any other day gives the 1st of the following month) and replaces the earlier one; the earlier insurance start date is no longer treated as valid. How the corrected date reaches the pension fund is a separate topic (out of scope here).
  - _Sources: F-hr_transcript-e18e66, F-hr_transcript-1d5c07, G-04_

  | Example | First working day | → | Pension insurance start date | Checked |
  |---|---|---|---|---|
  | Julia moved her start to 15.03 (hr_transcript/F-hr_transcript-e18e66), year illustrative | 15.03.2026 | → | 01.04.2026 | ✅ |
  | Start moved one week earlier onto the 1st of a month (illustrative) | 01.04.2026 | → | 01.04.2026 | ✅ |
  | Start moved within the same month (illustrative) | 08.04.2026 | → | 01.05.2026 | ✅ |


## Evidence
- **F-hr_transcript-1d5c07** (hr_transcript, inferred): Consolidated rule: the insurance start date is derived from the first working day. If the first working day is the 1st of a month, insurance starts that day. Otherwise it starts on the 1st of the following month.
  - "because insurance starts on the first of the following month." — hr_transcript/T-026, Anna
  - "Unless somebody starts exactly on the first, of course, then it's just that day." — hr_transcript/T-028, Anna
- **F-hr_transcript-e18e66** (hr_transcript, inferred): When the first working day changes, the insurance start date given to the pension fund must be re-derived and updated. A missed update (Julia) caused a wrong date at the fund, an unfriendly letter and weeks of fixing.
  - "She moved her first working day to the 15th of March, and I didn't update it." — hr_transcript/T-026, Anna
  - "I got a very unfriendly letter." — hr_transcript/T-026, Anna
  - "It took weeks to fix." — hr_transcript/T-028, Anna
- **F-hr_transcript-e3721e** (hr_transcript): The employee should confirm the first working day, because it changes often (for example, when people negotiate an earlier exit with their old employer).
  - "I ask them to confirm it, because it moves more often than you'd think." — hr_transcript/T-024, Anna
  - "People negotiate with their old employer, they get out a week earlier." — hr_transcript/T-026, Anna
