# US-08.2 – Discard answers that no longer apply on submission

Part of [Employee onboarding questionnaire](../feature.md), section [8. Completing and submitting the questionnaire](../feature.md#SEC-08-completion-and-submission).

**As** new employee, **I want** answers to questions that no longer apply after I change an earlier answer to be kept while I move back and forth, but dropped when I submit, **so that** I lose no input while correcting myself, and Lonio records no personal data about me that no receiving party needs

Priority **P1** – Data minimisation is a core constraint of the feature (G-01): keeping answers no party needs means holding personal data Lonio must not have. · Status: **decision** · Sources: G-01, D-036

> ⚠ Open questions affecting this section: [OQ-copy-email-retention](../open-questions.md#oq-copy-email-retention)
Covers (details in [the section](../feature.md#SEC-08-completion-and-submission) and [information.md](../information.md)): Discard answers that no longer apply

## Acceptance criteria

- **AC-08.2.1 Answers are kept while the employee goes back and forth**
  - **Given** an employee has answered follow-up questions and then changes an earlier answer so that those follow-up questions no longer apply
  - **When** the employee changes the earlier answer back before submitting
  - **Then** the follow-up questions apply again and show the employee's earlier answers, so no input is lost
  - _Sources: D-036_
- **AC-08.2.2 Only answers to questions that still apply are recorded on submission**
  - **Given** an employee's latest answers mean that some questions they had answered earlier are no longer asked
  - **When** the employee submits the questionnaire
  - **Then** the answers to the questions that are no longer asked are discarded and not recorded for HR or any receiving party; only the answers to questions that apply to the latest answers are recorded
  - _Sources: G-01, D-036, D-034_

## Evidence
- **D-034** (product decision (Product owner)): Only the employee side is in scope. Who starts the onboarding and any HR screen are specified later; the spec says answers are recorded for HR, not 'available to HR'. HR-side needs from D-007 (flag) and D-033 (HR changes the date) are noted for that later spec.
- **D-036** (product decision (Product owner)): Answers to questions that no longer apply after the employee changes an earlier answer are discarded on submission; until then they may be kept so going back and forth loses no input.
- **G-01** (product owner guidance): Lonio collects onboarding data from a new employee **once** and reuses it for every receiving party. Asking too little blocks a registration; asking too much collects personal data we must not have (data minimisation). A question must only be asked when at least one receiving party needs the answer for this person.
