# US-08.4 – Liechtenstein: daily return and more than 45 non-return days

Part of [Employee onboarding questionnaire](../feature.md), section [8. Source tax: residence abroad and cross-border questions](../feature.md#SEC-08-cross-border-residence).

**As** source tax office, **I want** every employee living in Liechtenstein to state first whether they expect to return daily to their main residence in Liechtenstein and, if not, whether they expect more than 45 work-related non-return days in the calendar year, **so that** Lonio records, as the Zurich calculator does, either 'in principle no source tax liability, subject to the double taxation agreement' or the normal tariff code with the double taxation agreement reservation, and flags the case for HR

Priority **P1** – Liechtenstein residents work at Muster AG (F-hr_transcript-3f2c2a); Lonio now owns the tariff result (D-001) and must not ask needless tariff questions when there is in principle no liability (G-01). · Status: **decision** · Sources: F-zh_source_tax_calculator-981b6b, F-zh_source_tax_calculator-a2041b, F-zh_source_tax_calculator-e22d17, F-zh_source_tax_calculator-e96210, F-zh_source_tax_calculator-0ff846, F-zh_source_tax_calculator-f4ece9, F-zh_source_tax_calculator-fb87f1, F-zh_source_tax_calculator-cc19c7, F-hr_transcript-3f2c2a, F-hr_transcript-5af8d0, G-01, D-001, D-006, D-007, D-034, D-035, D-040, D-045

Covers (details in [the section](../feature.md#SEC-08-cross-border-residence) and [information.md](../information.md)): Daily return to Liechtenstein, More than 45 non-return days (Liechtenstein), Liechtenstein: in principle no source tax liability, Cross-border tariff applies

## Acceptance criteria

- **AC-08.4.1 Liechtenstein residents are asked about daily return first**
  - **Given** the employee's home address on the first working day is in Liechtenstein (so HR's rule makes them subject to source tax whatever their nationality)
  - **When** the employee reaches the source tax questions
  - **Then** before denomination, spouse and children questions, the employee is asked whether they expect to return daily to their main residence in Liechtenstein, answered 'yes' or 'no'; the answer is required. With 'no' they are then asked whether they expect more than 45 work-related non-return days in the calendar year, answered 'yes' or 'no' and required. The employee states their expectation for the year. Asking before the tariff questions is an assumption to be verified by a domain expert (D-040)

- **AC-08.4.2 In principle no source tax liability: tariff questions skipped**
  - **Given** the employee lives in Liechtenstein and either expects to return daily, or does not return daily and expects at most 45 non-return days
  - **When** Lonio determines the source tax result
  - **Then** Lonio records 'in principle no source tax liability, subject to the double taxation agreement' instead of a tariff code, flags it for HR, and does not ask the denomination, spouse and children questions for source tax. How HR sees the flag is specified in the later HR-side spec (see OQ-hr-side-follow-ups). This follows the calculator; asking these residents at all is a decision to be verified by a domain expert (D-007)
  - _Sources: F-zh_source_tax_calculator-fb87f1, G-01, D-007, D-034, D-040_

- **AC-08.4.3 More than 45 non-return days: normal tariff with DTA reservation**
  - **Given** the employee lives in Liechtenstein, does not expect to return daily and expects more than 45 non-return days
  - **When** Lonio determines the source tax result
  - **Then** the tariff questions (denomination, spouse, children) are asked, the normal tariff code is computed (never the cross-border tariff, which applies only to Germany residents) and recorded with the note 'subject to the double taxation agreement', flagged for HR. The result is always derived again from the latest answers. Recording the note and the flag is an assumption to be verified by a domain expert (D-040)
