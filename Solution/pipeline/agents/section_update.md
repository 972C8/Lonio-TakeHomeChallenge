# Updating a section that was written before

This section's stories already exist and people have read them. Only some
elements of the knowledge model changed (listed below).

- Update the section for these changes only. Keep every story, criterion and
  example they do not affect word for word, with the same ids.
- A new element that no existing story covers gets a new story with the next
  free number. Don't fold it into an existing story unless that story's goal
  needs it.
- In a story you must change, change only the sentences, criteria and examples
  the changed elements affect. Keep the rest word for word.
- Don't renumber, reorder, retitle or reprioritise stories the changes don't
  affect.
