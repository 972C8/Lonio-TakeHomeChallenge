Domain guidance for **address change** (product owner).

- [G-01] Ask only what a stakeholder needs for this person (data minimisation).
- [G-02] Business wording for values: countries by English name
  ("Switzerland", "Germany"), dates as DD.MM.YYYY, yes/no as "yes"/"no".
- Use these information item ids when the concept exists: new_street,
  new_house_number, new_postcode, new_town, new_country, new_canton,
  valid_from, previous_canton.
- Use this rule id when it exists: payroll_must_be_informed.
